# Franz Barrido Portfolio (Next.js, JSX)

## Before running: copy your images into /public
profile1.png, mongodb11.png, express21.jpg, react1.png, node1.png,
awesometodos1.png, classe1.jpg, webprofile1.png
(the same files from your old project's public folder). Missing images fall back to placeholders.

## Run locally
npm install
npm run dev   # http://localhost:3000

## Deploy to Vercel
Push to GitHub > vercel.com > Add New > Project > import > Deploy (or `npx vercel`).

## Editing content
All text lives in data/ (profile.js has name, about, contact info).
Experience and Certificates sections stay hidden until you add entries to
data/timeline.js and data/certificates.js.
